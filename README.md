# 🧺 Pedidos de Cestas Agroecológicas

## Sobre o projeto

Sistema web desenvolvido para facilitar a organização e o gerenciamento de pedidos de cestas agroecológicas.

A aplicação possui duas áreas principais: uma área destinada aos clientes e uma área administrativa para gerenciamento das informações e dos pedidos.

O projeto foi pensado a partir de uma necessidade real de organização das encomendas de produtos agroecológicos.

---

## 🎯 Problema

A organização dos pedidos de cestas pode envolver mensagens, listas e informações espalhadas, dificultando o controle dos produtos disponíveis, valores e pedidos realizados pelos clientes.

O sistema busca centralizar essas informações em um único ambiente.

---

## 💡 Solução

A aplicação permite que os administradores mantenham atualizada a lista de produtos e valores disponíveis. Tem acesso aos pedidos dos clientes e um resumo de todos os pedidos para facilitar no momento da colheita.

O cliente acessa a área de pedidos, informa seus dados e seleciona os produtos que deseja.

Durante o pedido, o sistema apresenta os produtos disponíveis e seus respectivos valores, além de possibilitar a apresentação de informações para pagamento via PIX.

---

## 👤 Área do cliente

Na área do cliente é possível:

- Informar nome e celular
- Visualizar os produtos disponíveis
- Consultar os valores dos produtos
- Selecionar os produtos desejados
- Realizar o pedido
- Visualizar informações de pagamento via PIX.
---

## ⚙️ Área administrativa

A área administrativa permite a organização das informações utilizadas no processo de pedidos.

Entre as funções estão:

- Gerenciamento da lista de produtos
- Atualização de produtos disponíveis
- Atualização de valores
- Organização dos pedidos realizados
- Gerenciamento das informações utilizadas no atendimento aos clientes

---

## 🌱 Contexto

O projeto foi desenvolvido considerando a realidade da comercialização de produtos agroecológicos e a necessidade de facilitar o processo de encomendas das cestas.

A proposta é tornar o processo mais organizado tanto para quem realiza os pedidos quanto para quem administra as encomendas.
